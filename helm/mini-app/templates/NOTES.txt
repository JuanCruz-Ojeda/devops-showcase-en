mini-app deployed as release "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

  App:   {{ .Values.app.replicaCount }} replica(s)  (Deployment)
  Redis: 1 replica  (StatefulSet, PVC {{ .Values.redis.persistence.size }})

Test the app:

  kubectl port-forward svc/{{ include "mini-app.fullname" . }} 8080:{{ .Values.app.service.port }}
  curl -fsS http://localhost:8080/health
  curl -fsS http://localhost:8080/cache-test

Run the chart tests:

  helm test {{ .Release.Name }}

Scale the app to 3 replicas:

  helm upgrade --install {{ .Release.Name }} ./helm/mini-app --set app.replicaCount=3
